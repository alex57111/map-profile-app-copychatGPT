# Попутчик — Карта + Профиль

> Этот репозиторий — клон `alex57111/map-profile-app` (история сохранена,
> оригинал не меняется). Здесь ведётся миграция в Telegram Mini App.
> Актуальный статус, что сделано и что нет — всегда в `AGENT_LOG.md`,

- Leaflet + OSM
- OSRM маршрутизация
- Mock-режим (без Supabase)

## Запуск
```bash
npm install
```
